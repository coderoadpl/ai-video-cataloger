# Foundation

This repository is a ground-up rewrite built on top of the agentproofarch
foundation: <https://github.com/chomamateusz/agentproofarch>.

Forked at: foundation docs as of 2026-07-12 (see
[`docs/architecture.md`](docs/architecture.md)).

The delta against the foundation's architecture — what this app overrides,
adds, or removes — lives in [`docs/architecture.md`](docs/architecture.md),
written as a delta against the foundation's own `docs/architecture.md`:
foundation rules apply here except where that document overrides them.
