## Codebase Patterns
- Use `electron-store` for persisting settings between sessions (window state, etc.)
- TypeScript configs are split: electron/tsconfig.json for main process, electron/tsconfig.renderer.json for React
- IPC handlers in electron/main/ipc-handlers.ts follow pattern: ipcMain.handle('channel-name', async (_event, args) => { ... })
- Preload script exposes API via contextBridge.exposeInMainWorld('electronAPI', {...})
- CSS uses CSS variables defined in global.css for consistent theming
- Components import their own CSS files (e.g., `import '../styles/Toolbar.css'`)
- FFmpeg setup: Call `configureFfmpeg()` from ffmpeg-setup.ts before any ffmpeg operations
- Bundled binaries: Use `getFFmpegPath()` and `getFFprobePath()` from ffmpeg-paths.ts for binary locations
