## Codebase Patterns
- Use sql.js instead of better-sqlite3 (native module compatibility with Node.js v25)
- ESM modules ("type": "module" in package.json)
- TypeScript strict mode enabled
- Entry point: src/index.ts with shebang
- Use execa for running shell commands (already a dependency)
- Use chalk for colored terminal output (already a dependency)
- Services are exported through src/services/index.ts barrel export
- Database exports through src/db/index.ts barrel export
- Utilities are exported through src/utils/index.ts barrel export
- Database file stored in .ai-video-cataloger/catalog.db (auto-created)
- Call saveDatabase() after each database modification (sql.js is in-memory)
- Video extensions: .mp4, .mov, .avi, .mkv, .webm
- Use fluent-ffmpeg for video/audio operations (ffprobe for metadata, ffmpeg for extraction)
- Frame/transcript/summary directories stored in same directory as videos (e.g., frames/{video-name}/)
- Temp audio files stored in OS temp directory using getTempAudioPath(videoPath)
- Claude CLI for analysis: `claude --add-dir <dir> -p <prompt>` with file:// URLs in prompt for images (NOT as positional args)
- Claude CLI requires stdin: 'ignore' in execa to prevent hanging
- Analysis response format: DESCRIPTION: <text> FILENAME: <kebab-case-name>
- OpenAI Whisper API: `openai.audio.transcriptions.create({ file: createReadStream(path), model: 'whisper-1' })`
- Local Whisper CLI model selection: `whisper <audio> --model <model>` (models: tiny, base, small, medium, large-v3)
- @inquirer/prompts for interactive menus: `select()`, `number()`, `confirm()` (NOT legacy inquirer.prompt)
- Local Whisper models stored in `~/.cache/whisper/` as `.pt` files (e.g., base.pt, tiny.pt)
- Commander.js subcommands: use `program.command('name')` for subcommand groups, then chain `.command('action')` for actions
