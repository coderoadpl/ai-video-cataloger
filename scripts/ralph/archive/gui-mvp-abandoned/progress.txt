## Codebase Patterns
- Use sql.js instead of better-sqlite3 for Node.js compatibility
- Use @inquirer/prompts instead of inquirer for terminal compatibility
- Claude Code CLI requires file:// URLs in prompt text to read images
- Use stdin: 'ignore' in execa calls to prevent subprocess hanging
- Existing services in src/services/ can be reused by Electron main process
- Use electron-store for persisting app preferences (recent folders, setup state)
- For Electron IPC, expose minimal API via preload.ts using contextBridge
- Use ffmpeg-static with .replace('app.asar', 'app.asar.unpacked') for bundled binary path
- Ollama HTTP API at localhost:11434 for LLaVA integration
- Auto-start Ollama via spawn('ollama', ['serve'], { detached: true, stdio: 'ignore' })
- Detect RAM with os.totalmem() to recommend LLaVA model size
