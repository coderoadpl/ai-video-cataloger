## Codebase Patterns
- Use sql.js instead of better-sqlite3 for Node.js compatibility
- Use @inquirer/prompts instead of inquirer for terminal compatibility
- Claude Code CLI requires file:// URLs in prompt text to read images
- Use stdin: 'ignore' in execa calls to prevent subprocess hanging
- Existing services in src/services/ can be reused by Electron main process
