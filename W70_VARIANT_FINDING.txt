The photo detail variant selector has no code path that opens or focuses it without user interaction. I checked the MUI Select in PhotoDetailPane for autoFocus, defaultOpen, a controlled open value, refs, and focus callbacks; none are present. I also traced the shared VariantControl wrapper, PhotosWorkspace selection flow, and photo selection/data-loading state for focus calls or effects that target the control, and found none. VariantControl only lays out the supplied control and caption, while selecting a photo only updates the fingerprint and loads detail and variant data. Because there is no automatic-open or focus-stealing mechanism to reproduce or test, W70 makes no speculative variant-selector code change.
