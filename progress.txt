## Codebase Patterns
- Follow ffmpeg-setup.ts pattern for bundling external binaries: path resolution with bundled first, system fallback
- Use `createRequire(import.meta.url)` for CommonJS module imports in ESM context
- Services that depend on binary setup should call `configureX()` at module load time
- Model files: GGML format (.bin) for whisper.cpp, PyTorch format (.pt) for OpenAI Whisper Python
- User data locations: `~/.ai-video-cataloger/bin/` for binaries, `~/.ai-video-cataloger/models/` for models
- JSON output mode: Use json-output.ts service for NDJSON events (started, progress, completed, error)
- For subcommands, add `--json` option and use `command.optsWithGlobals<{ json: boolean }>()` to get the option value (Commander.js bug with same-named options on parent and child commands)
- Use `isJsonMode()` to branch between JSON and human-readable output
- For single-file processing commands, use `resolve()` to get absolute path and `dirname()` for parent folder
- Thumbnail storage pattern: Store in `.ai-video-cataloger/thumbnails/` using video filename (without ext) + .jpg
- Model download URLs: GGML models from https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-{modelName}.bin
- Electron structure: electron/main/ (main process), electron/preload/ (preload script), electron/renderer/ (React app)
- Each Electron context has its own tsconfig.json with specific settings (main/preload use NodeNext, renderer uses bundler)
- Typecheck script must check all contexts: CLI (src/), main, preload, and renderer
- Vite dev server for renderer, compiled TypeScript for main/preload
- Output to dist-electron/ for Electron, dist/ for CLI
- Tailwind CSS v4: Use `@import "tailwindcss"` and `@theme {}` block for configuration (no tailwind.config.ts)
- Tailwind CSS v4: PostCSS uses `@tailwindcss/postcss` plugin instead of `tailwindcss`
- Tailwind CSS v4: Define colors as `--color-{name}` in @theme block, auto-generates `bg-{name}`, `text-{name}` utilities
- shadcn/ui components: Store in `electron/renderer/src/components/ui/`
- cn() utility: Use clsx + tailwind-merge in `electron/renderer/src/lib/utils.ts`
- Path aliases: Add `baseUrl` and `paths` to tsconfig.json for `@/*` imports
- IPC pattern: Use ipcMain.handle() for async request/response, ipcMain.on() for one-way messages
- IPC streaming: Use webContents.send() from main to renderer for streaming events (stdout, stderr, json, exit)
- Preload listeners: Return cleanup function from event listeners (e.g., onStdout returns () => removeListener)
- CLI spawner: spawn with node + CLI path, stream via readline createInterface, track processes for cleanup
- TerminalLog component: Store in `electron/renderer/src/components/` (not ui/ - it's an app component)
- ANSI parsing: Use regex `/\x1b\[([0-9;]*)m/g` to parse escape sequences, map codes to Tailwind classes
- Auto-scroll pattern: Track user scroll position, disable auto-scroll when user scrolls up, show "Scroll to bottom" button
- Layout components: Store in `electron/renderer/src/components/layout/` for structural components (AppLayout, ResizablePanel)
- Window state persistence: Use `app.getPath('userData')` for config file, save on close/resize/move with debounce
- ResizablePanel: Use mouse events with direction (horizontal/vertical), track dragging state, apply delta to size
